# Intro

**01-core-infra** is an Ansible-managed infrastructure automation suite for deploying and maintaining a homelab environment on a Raspberry Pi 5. It manages Docker services, systemd units, cron jobs, and credential sync across self-hosted applications.

## Overview

This repository is the single source of truth for your homelab's core infrastructure. It provides:

- **Declarative deployment** — infrastructure-as-code using Ansible playbooks
- **Component registry** — a catalog of all services, their types, and deployment methods
- **Template-based configuration** — edit templates, deploy via Ansible, never touch runtime dirs
- **Credential management** — mesh sync engine that harvests and distributes API keys
- **Monitoring** — automated healthchecks and backups on a schedule

## Quick Start

```bash
# Bootstrap installer
curl -fs https://raw.githubusercontent.com/Aldo-f/01-core-infra/main/install.sh | bash

# Full deployment
cd ansible && ansible-playbook -i inventories/local.yml playbooks/site.yml
```

The installer clones the repository, validates the version tag, and runs the deployment script. After that, simply run the Ansible playbook to deploy all infrastructure components.

## Key Files

| File | Purpose |
|------|---------|
| `install.sh` | Bootstrap installer — clones repo at tagged version, validates tag, shallow clone, then execs `scripts/deploy.sh` |
| `scripts/deploy.sh` | Full deployment logic extracted from the original installer |
| `AGENTS.md` | System documentation for AI coding agents working with this repo |

## Architecture Philosophy

```
~/dev/01-core-infra/
  templates/infra/<component>/   ← EDIT HERE (source of truth)
  ansible/                       ← Deployment automation
  plex/ portainer/ qbittorrent/  ← NEVER TOUCH (generated by Ansible)
```

**Naming convention determines target:**
- `01-core-*` — inside this repo (`01-core-infra/<name>/`)
- `04-network-*` — sibling repo (`~/dev/04-network-<name>/`)
- `02-*`, `06-*` — own git repos (cloned via manifest, only `infra/` subdir overwritten)

## Requirements

- Raspberry Pi 5 running Raspberry Pi OS (Linux 6.18+)
- Ansible 2.18+
- Docker + Docker Compose v2 plugin
- Git
- NVM with Node.js 20+
